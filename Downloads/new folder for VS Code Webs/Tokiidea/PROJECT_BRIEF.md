# Tokiidea Website Project Brief

## Overview
**Store Name**: Tokiidea  
**Product**: Handmade plushies  
**Target Audience**: People who love fun decor/style (like blindbox culture) and plushies, interested in handmade items  
**Launch Approach**: MVP (Minimum Viable Product) - store + essentials first, similar to yeezy.com simplicity  

## Design Inspiration & Aesthetic
### From choutopia.com & thepigroom.com:
- **Color Palette**: Soft pastel tones (pinks, light blues, creamy whites, muted pinks, light greys)
- **Typography**: 
  - Headings: Rounded, hand-written-style or friendly sans-serif (reads like handwritten notes)
  - Body: Clean, legible sans-serif
- **Layout**: Card-based/product grid with ample white space
- **Whimsical Touches**: 
  - Character-themed elements (subtle references)
  - Doodle-style icons
  - Playful badges/labels (e.g., "sold out :(")
  - Community/user-generated content elements
  - Hand-drawn or illustrated accents
- **Vibe**: Warm, approachable, slightly nostalgic, gentle, cozy, inviting, friendly yet readable

### From yeezy.com (Simplicity Principles):
- **Minimalist Navigation**: Essential links only
- **Ample White Space**: Clean, uncluttered layouts
- **Focus on Product**: Large, clear product imagery
- **Simple Typography**: Clean, readable fonts
- **Straightforward User Experience**: Intuitive flow from discovery to purchase
- **Monochromatic/Neutral Base**: With pastel accents for Tokiidea

## Required Pages & Features
1. **Homepage** - Featured products, brand introduction
2. **Shop/Store Page** - All products in grid/list view
3. **Product Detail Pages** - Individual product info, photos, price, add to cart
4. **About Page** - Brand story, maker bio, creative process
5. **Contact Page** - Contact form, email, social media links
6. **FAQ Page** - Shipping, returns, custom orders, care instructions
7. **Policy Pages** (in footer):
   - Terms of Service
   - Privacy Policy
   - Cookies Policy
   - Shipping Policy
   - Returns & Refunds Policy
8. **Footer** - All policy links + social media icons
9. **Header** - Simple navigation (Home, Shop, About, Contact, Cart)

## Technical Approach
- **Basic HTML/CSS** (as requested)
- **Stripe Integration** for e-commerce (user has account ready)
- **Responsive Design** (mobile-friendly)
- **Static Site** (can be hosted on GitHub Pages, Netlify, Vercel, etc.)
- **No JavaScript frameworks** for MVP (vanilla HTML/CSS/JS only if needed for Stripe)

## Design Tokens (Starting Point)
### Color Palette (Pastel + Neutral)
- Primary Pastel: #F8EDEB (Blush Pink)
- Secondary Pastel: #E8F4FD (Baby Blue)  
- Neutral Base: #FFFFFF (White)
- Neutral Dark: #F5F5F5 (Light Grey)
- Accent: #D4B483 (Soft Sage) or #E6B3AA (Dusty Rose)
- Text: #333333 (Dark Grey for readability)

### Typography Suggestions
- Headings: "Quicksand", "Rounded Mplus", "Nunito", or "Comic Neue" (rounded, friendly)
- Body: "Inter", "Helvetica Neue", "Arial", or "system-ui" (clean, readable)

### Layout Principles
- Card-based product display
- Ample padding/margin (white space)
- Consistent product card dimensions
- Clear visual hierarchy
- Mobile-first responsive breakpoints
